Reconnaître le matériel sous plusieurs angles

Regarde les formes générales, puis les indices qui changent peu d’une photo à l’autre : roues ou chenilles, nombre de moteurs, ailes, rotor, empennage et équipements visibles. Chaque fiche propose plusieurs vues quand une source fiable est disponible.

Mode hors ligne : les photos conservées dans le dossier photos restent disponibles hors ligne. Les photos externes demandent une première consultation avec Internet pour être mises en cache par l’application. L’illustration de secours s’affiche si une photo ne peut pas être chargée.

Les appellations suivent ta liste et les légendes des sources photographiques. Le nom « Hemington » dicté est rapproché de « Remington », comme sur la note manuscrite « M24 Remington ». Le nom « Spear Firefly » est rapproché de « Spike FireFly », écrit dans tes notes.
